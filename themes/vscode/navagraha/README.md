# Graha – VS Code

Vier Farbschemata aus einem siderischen Geburtshoroskop (Lahiri):
23.05.1982, 19:47 MESZ, Wedel.

| Theme            | Grund   | Helligkeit | Herleitung des Grundtons                       |
|------------------|---------|------------|------------------------------------------------|
| Graha Pratipada  | Prithvi | dunkel     | Erd-Gruppe in Vrishabha und Kanya, Farbton 76°  |
| Graha Ushas      | Prithvi | hell       | dieselbe                                        |
| Graha Swati      | Vayu    | dunkel     | Lagna Tula, Guru in Swati, Farbton 255°         |
| Graha Tula       | Vayu    | hell       | dieselbe                                        |

Die Graha-Akzente sind in allen vier identisch, nur der Grundton wechselt.

## Zuordnung

Ketu Kommentare · Chandra Bezeichner · Mangala Schluesselwoerter · Budha Zeichenketten ·
Guru Funktionen und Selektoren · Shani Operatoren · Surya Zahlen und Konstanten ·
Shukra Typen und Eigenschaftsnamen · Rahu Praeprozessor, At-Rules und Tags

## Installation

    rm -rf ~/.vscode/extensions/graha-vscode
    unzip graha-vscode.zip -d ~/.vscode/extensions/

VS Code neu starten, dann Cmd+K Cmd+T.
